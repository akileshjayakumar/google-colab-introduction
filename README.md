# Welcome to Colab!
This repository provides introductory notebooks and resources for working with Google Colab and the Gemini API.

## Quick Start
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install jupyter
jupyter notebook Welcome_To_Colaboratory.ipynb
```
